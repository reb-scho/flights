# flights
Exploratory analysis of the U.S. Department of Transportation's '2015 Flight Delays and Cancellations' dataset.

# ✈️ Flight Delay Analysis

## Overview
This project analyses flight departure delays to understand:
- When delays are most severe
- What factors contribute most to delays

## Dataset
- Source: [https://www.kaggle.com/datasets/usdot/flight-delays?utm_source=chatgpt.com]
- Rows: 494777 flights (filtered for June)

## Key Insights
- Evening flights show higher average delays
- Airline and late aircraft delays are major contributors
- Delay patterns vary significantly by time of day
